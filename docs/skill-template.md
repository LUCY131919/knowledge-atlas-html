# Skill 页面模板

本模板用于创建一个新的 skill 页面，统一写作结构，方便后续维护和检索。

---

# {Skill 名称}

一句话描述：

例如：将复杂问题拆解为基本事实与关键约束的思维方法。

## 一、定义

在这里写清楚这个 skill 是什么，以及它解决什么问题。

## 二、关键要点

- 要点一
- 要点二
- 要点三

## 三、适用场景

- 场景 A
- 场景 B
- 场景 C

## 四、实践案例

描述一个真实或模拟的案例，以及该 skill 如何应用。

## 五、练习与复盘

- 练习题 1
- 练习题 2
- 复盘模板：问题 → 观察 → 结论 → 行动

## 六、扩展阅读

- 书籍、文章、课程或参考链接

---

使用原则：

- 内容尽量简洁但不失结构
- 每个 skill 关注“定义、方法、应用、复盘”四个部分
- 优先强调“如何使用”，而不是纯概念堆叠
