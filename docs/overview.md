# Overview — 关于知识星球 Skill

本文件介绍这个知识库的设计理念、结构和维护方式，方便后续扩展和协作。

## 1. 项目的核心理念

知识星球 Skill 不是普通的文档集合，而是一个以 skill 为主导的知识网络。

每个 skill 都包含以下要素：

- 概念定义
- 核心要点
- 适用场景
- 实践案例
- 复盘方法
- 参考资料

目标是把知识变成可复用、可迭代的思维工具，而不是零散的信息堆砌。

## 2. 设计原则

1. Skill 为原子单元：每个知识点都可被独立学习和应用
2. 认知优先：强调理解、判断和决策，而不只强调信息量
3. 领域联动：连接产品、商业、管理、技术、认知和个人成长等方向
4. 结构化组织：以目录和主题分类来支撑知识的持续扩展
5. 可迭代开发：允许持续补充案例、更新思维模型和改进结构

## 3. 推荐目录结构

- README.md：项目总体说明
- index.html：知识星球首页
- docs/
  - overview.md：设计说明
  - skills.md：skill 总目录
  - skill-template.md：skill 页面模板
  - skill-*.md：各个具体 skill 页面
- examples/：案例与练习
- assets/：样式和图片资源
- data/：结构化索引（如 JSON/YAML）
- CONTRIBUTING.md：贡献说明

## 4. 适合的学习路径

建议按从基础到应用的顺序组织内容：

- 认知基础：第一性原理、系统思维、反向思考
- 决策分析：二阶思维、机会成本、结构化决策
- 学习方法：费曼学习法、复盘法、反馈机制
- 领域应用：产品、管理、技术、商业等行业视角

## 5. 扩展方式

- 新增 skill 页面：按照 `docs/skill-template.md` 的结构创建
- 补充案例：在 `examples/` 下增加真实场景案例
- 建立目录索引：更新 `docs/skills.md`
- 改进显示内容：继续增强首页的导航和结构化表达

## 6. 最终目标

本项目最终希望发展成为：

“一个以 skill 为核心、以知识地图为结构、以认知提升为方向的知识星球。”
