# Skill 知识星球（Knowledge Atlas）

## 简介

这是一个面向技能与行业认知的知识星球集合，旨在汇总各领域的核心知识、学习路径、资源导航和实战案例，帮助提升行业认知与思维能力。

仓库地址：
- GitHub: https://github.com/LUCY131919/knowledge-atlas-html

## 项目目标

- 将各领域的知识进行结构化整理
- 帮助学习者建立系统认知框架
- 提供可持续扩展的知识地图
- 促进知识共享、协作和持续更新

## 目录结构

```text
.
├── README.md
├── index.html
├── assets/
├── docs/
├── knowledge/
├── categories/
└── ...
```

说明：
- `index.html`：首页入口
- `knowledge/`：各领域/主题的知识内容
- `categories/`：分类导航与知识地图
- `docs/`：说明文档和扩展资料
- `assets/`：图片、样式、静态资源

## 适用场景

- 学习某个行业/领域的基础知识
- 建立知识图谱和学习路线
- 组织技术/业务/管理类学习资料
- 作为个人知识库或团队共享知识平台

## 使用方式

1. 访问仓库中的首页或相关页面
2. 按领域/主题查看内容
3. 根据需要展开知识点和学习资料
4. 如有改进建议，可提交 Issue 或 Pull Request
