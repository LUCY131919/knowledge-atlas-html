# 知识星球 Skill

> 以 skill 为核心：围绕思维模型、认知框架与各领域知识方法，构建可学习、可复用的知识星球。

## 项目定位

知识星球 Skill 是一个面向跨领域认知提升的知识库。它不是单纯的资料整理，而是一套“技能化”的知识体系。每个 skill 都围绕一个具体的思维模型、认知方法或行业能力展开，帮助学习者理解问题、分析结构、形成判断，并持续提升认知和决策能力。

我们的目标不是堆砌信息，而是帮助使用者建立一张可持续扩展的知识地图。

---

## 核心理念

- Skill 优先：每个知识点都可形成可学习、可应用的能力单元
- 领域联动：覆盖产品、管理、技术、经济、决策、人际与个人成长等多个方向
- 认知提升：强调思考框架、判断逻辑、方法论和复盘能力
- 知识星球：通过结构化目录，将零散内容组织成可扩展的知识体系

## 使用方式

1. 打开首页 `index.html`，浏览各类 skill 与学习方向
2. 进入 `docs/skills.md` 查看知识目录
3. 根据兴趣选择某个 skill 深入学习和实践
4. 在 examples/ 中补充案例和实践复盘
5. 按模板创建新的 skill 页面并持续扩展知识星球
